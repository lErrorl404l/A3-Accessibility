# A3 Accessibility

Accessibility modes for Arma 3, built for players with colour vision deficiency.

## Colour-blind modes

Select a mode in the CBA settings menu under "A3 Accessibility". Each mode remaps the map marker
colours, so friendly, enemy, neutral and unknown units stay distinguishable without relying on the
red-green axis.

Modes: Off, Protan, Deutan, Tritan, Achromatopsia.

The addon remaps colours. It does not apply a screen filter.

## Requirements

- Arma 3 2.12 or later
- CBA_A3

## Status

In development. The colour-blind modes are the first feature. Further accessibility features are
planned and recorded in the project research.
